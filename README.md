# 🕵️ الدخيل — مين برّا السالفة؟

لعبة جماعية مضحكة تنلعب على المتصفح من جهاز واحد (٣ لاعبين أو أكثر).
كل اللاعبين يشوفون نفس الكلمة السرية إلا **الدخيل** 🤡 — لازم تكشفونه قبل لا يعرف الكلمة!

## التشغيل
افتح `index.html` بأي متصفح (موبايل أو كمبيوتر). ما تحتاج تنصيب ولا سيرفر.

## المميزات
- 🎰 **عشوائي كامل**: ماكينة حظ تختار كل جولة الفئة، نوع اللعب، عدد الدخلاء، والمفاجأة
- 🎁 ١٤ مفاجأة عشوائية: نقاط مضاعفة، جاكبوت الدخيل، تلميحة أول حرف، الدخيل أعمى، دخيلين، جولة سريعة، جولة مصرية، الهمس، الروبوتات...
- 🏁 مباريات (٣/٥/٧/١٠ جولات أو بلا نهاية) مع منصة تتويج 🥇🥈🥉 وعقاب للأخير
- 🎖️ رتب وترقيات للاعبين: مبتدئ 🐣 ← هاوي ← محقق 🔎 ← داهية 🦊 ← عبقري 🧠 ← أسطورة 🐐 ← خرافي 👑
- ⚡ لعب سريع بضغطة وحدة، و«فاجئني» يختار لعبة جانبية عشوائية
- 🎴 بطاقات سرية بحركة قلب، تمرير الجهاز بين اللاعبين
- 🗂️ ٢٢ فئة (أكثر من ٦٥٠ كلمة، وما تتكرر الكلمات بسرعة) (أكلات، أكلات شعبية، حيوانات، دول، مدن، مهن، رياضة...) + فئات خاصة تضيفها بنفسك
- 🎭 مودين: **كلاسيك** و **المتخفي** (الدخيل ياخذ كلمة قريبة وما يدري إنه دخيل!)
- 🕵️ أكثر من دخيل حسب عدد اللاعبين
- 🎤 جولات أسئلة مع مؤقت واقتراحات أسئلة
- 🗳️ تصويت سرّي أو جماعي، مع طبل وكشف درامي 🥁
- 🎯 الدخيل يخمّن الكلمة من بين خيارات
- ⭐ نقاط، لوحة صدارة، وألقاب (الثعلب 🦊، المحقق 🕵️، ملك الجلسة 👑...)
- 🎲 ألعاب جانبية: دولاب العقاب 🎡، مين الأكثر؟ 👉، مثّلها 🎭، صراحة لو تحدي 🔥
- 🔊 أصوات واهتزاز وكونفيتي، وكل شي ينحفظ بالمتصفح
