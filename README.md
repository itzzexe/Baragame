# 🎉 شلة الجودة

ألعاب جماعية مضحكة للجمعة، تنلعب على المتصفح من جهاز واحد تمررونه بيناتكم. افتح `index.html` بأي متصفح، ما تحتاج تنصيب.

## 🤡 اللعبة الأساسية: برّا السالفة
كل اللاعبين يشوفون نفس الكلمة السرية إلا اللي **برّا السالفة** — لازم تكشفونه بالأسئلة والتصويت قبل لا يعرف الكلمة!
- الحظ يختار منو برّا السالفة بالسر، والكلمة عشوائية من ٢٢ فئة (أكثر من ٦٥٠ كلمة)
- مود كلاسيك، مود المتخفي، أو نوع عشوائي
- مؤقت واقتراحات أسئلة، تصويت سري أو جماعي، كشف بالطبل 🥁، وتخمين الكلمة
- مباريات بمنصة تتويج 🥇، مفاجآت اختيارية، ودولاب عقاب للخسران
